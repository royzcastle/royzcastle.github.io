# royzcastle.github.io

Public profile / portfolio page for resume use. Scan the QR code on a resume to land here.

## Live

- Profile: <https://royzcastle.github.io/>
- AI Flash Report demo: <https://royzcastle.github.io/projects/flash-report/>

## What is here

- `index.html` — profile landing page
- `assets/` — profile styles and preview image
- `projects/flash-report/` — AI-enhanced executive flash report POC (static, zero dependencies)
- `projects/flash-report/teams/` — Microsoft Teams app manifest, icons and Adaptive Card
- `projects/flash-report/StarlightAIFlashReport-teams.zip` — sideload-ready Teams package
- `qr/` — ready-to-print QR codes for a resume

The flash report uses sample data and a fictional brand (Starlight Macau Integrated Resort) for demonstration only.

All pages carry a Confidentiality & Scope Notice: architectures are conceptualized reference models, data is synthetic/illustrative, no employer confidential information is disclosed, views are personal, and nothing here is financial, investment or legal advice.
