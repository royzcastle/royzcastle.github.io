# royzcastle.github.io

Public, framework-level project index for resume use. Scan the QR code on a resume to land here, then choose a project. All seven cards open a unified Project Detail page. Pages use anonymised, framework-level content.

## Live

- Project index: <https://royzcastle.github.io/>
- AI Executive Brief detail: <https://royzcastle.github.io/projects/flash-report/>
- Governed RAG Stack detail: <https://royzcastle.github.io/projects/rag-stack/>

## What is here

- `index.html` — project index / resume landing page
- `assets/` — index styles and preview image
- `projects/flash-report/` — AI-enhanced executive brief (flash report) project (static, zero dependencies)
- `projects/rag-stack/` — Governed RAG Stack showcase
- `projects/scope/` — framework-level scope pages for the remaining five projects (`?p=` selector)
- `projects/flash-report/teams/` — Microsoft Teams app manifest, icons and Adaptive Card
- `projects/flash-report/StarlightAIFlashReport-teams.zip` — sideload-ready Teams package
- `qr/` — ready-to-print QR codes for a resume (`qr-index.png` / `qr-profile.png` → project index; `qr-flash-report.png` → direct Executive Brief detail)

The executive brief uses sample data and a fictional brand (Starlight Macau Integrated Resort) for demonstration only.

All pages carry a Confidentiality & Scope Notice: architectures are conceptualized reference models, data is synthetic/illustrative, no employer confidential information is disclosed, views are personal, and nothing here is financial, investment or legal advice.
