02 / ENGINEERING NOTES

The decisions that made it work locally

01

Rule routing kept a weak model useful

Intent was classified by deterministic rules before generation. Even a small local base model could complete the chain; swapping in a stronger model only upgrades the final text, not the control flow.

02

BGE needed separate query / document embeddings

Chinese retrieval used a query instruction prefix and normalized vectors, stored in pgvector with cosine distance and an HNSW index. Query and document embeddings were computed differently on purpose.

03

Observation had a no-Docker fallback

When a Langfuse server was reachable, a registered v4 client sent traces to the UI. Otherwise every generation was written to local JSONL and Postgres so the demo never lost observability.

04

SFT ran CPU-only, in one day

A 0.6B guard model was LoRA-tuned on five domain rules with fp32 on a no-GPU machine, then validated for structured Safety: / Categories: output before merge and deployment planning.
